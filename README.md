# Customer Segmentation using K-Means

## 📌 Overview
This project performs customer segmentation using K-Means Clustering to group customers based on their income and spending score. It helps in understanding customer behavior and identifying different customer groups.

## 🎯 Objective
- Analyze customer data
- Identify patterns in customer behavior
- Segment customers into meaningful groups

## 📊 Dataset
The dataset contains:
- CustomerID
- Age
- Annual Income
- Spending Score

## ⚙️ Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## 📈 Methodology
1. Data Loading and Exploration
2. Data Cleaning and Checking Missing Values
3. Data Visualization (Age vs Income)
4. Applying Elbow Method to find optimal clusters
5. Applying K-Means Clustering
6. Visualizing Customer Segments

## 📉 Results
- Optimal number of clusters found: 5
- Customers are grouped based on income and spending behavior
- Different segments such as high spenders, low spenders, and average customers are identified

## 📷 Output
- Scatter plot (Age vs Income)
- Elbow Method graph
- Customer Segmentation graph with centroids

## 📌 Conclusion
Customer segmentation helps businesses understand their customers better and make data-driven decisions for marketing and growth.

## 📁 Output File
- customer_segments.csv (contains cluster information)
